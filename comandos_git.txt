git init .		-> Cira um repositório git na pasta tual
git status		-> Mostra o status do trabalho (de cada arquivo)
git add <nome arquivo>	-> Adiciona arquivo para ser comitado
git commit -m		-> Faz o commit do que estava para ser comitado
git log			-> Mostra todo o histórico de commit
git diff <nome arquivo>	-> Mostra o que foi adicionado ou removido do arquivo desde o último commit

## FLUXO DE TRABALHO
1. Criar o diretório do projeto.
2. Iniciar o git dentro do diretório criado (git init .).
3. Editar ou criar arquivos.
4. git add <nome do arquivo>
5. git commit -m Mensagem estranha"
6. Volta para o passo 3.
